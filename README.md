# Placement Readiness Checker

Welcome to the **Placement Readiness Checker**—a structured dashboard and evaluation tool designed to help students confidently prepare for campus placements. This web-based system provides a clear, quantitative readiness score along with personalized guidance based on a variety of critical evaluation points.

## 📖 About This App

The Placement Readiness Checker is built specifically for college students preparing for their first real-world interviews. Rather than offering generic advice, this platform evaluates you across multiple dimensions, giving you an accurate reflection of what employers look for. 

By testing your resume format, domain proficiency, computer science fundamentals, and behavioral response logic, this tool helps you identify your strengths and pinpoint exactly which areas need improvement before graduation.

## 🚀 What You Can Do

When using this application, you will go through a 4-step professional evaluation:

1. **Resume Review (20% Weightage)**  
   Upload your resume (PDF/DOCX). The tool will automatically parse the file, checking for content length, formatting properties, and the presence of essential sections (like Education, Projects, and Skills), as well as comparing your listed skills against industry-standard keywords.

2. **Skill Selection (20% Weightage)**  
   Map out your technical proficiencies. Select the programming languages, domains (e.g., Frontend, Backend, Cloud), and frameworks you are comfortable with to display your versatile knowledge stack.

3. **Technical Assessment (40% Weightage)**  
   Take a timed technical logic quiz. You'll encounter real-life Computer Science questions covering Data Structures, System Design, Object-Oriented Principles, and Database Management.

4. **Behavioral Test (20% Weightage)**  
   Simulate an HR interview round. You will be given workplace crisis scenarios—such as dealing with production bugs or handling critical code reviews—and your soft-skills will be evaluated based on your responses.

## 🛠️ Technology Stack

- **Frontend:** Next.js (App Router), React, Vanilla CSS (Clean Dashboard Style), Recharts (for the final skill matrix radar).
- **Backend:** Next.js API Routes for PDF Parsing.
- **Data Engineering:** Real-time client-side scoring logic bridging the gap between Node.js environments and React views.

## 🏁 Getting Started

1. Install all dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
