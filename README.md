# Placement Readiness Checker

A web-based system designed to help students understand how prepared they are for campus placements. This project provides a structured readiness score and personalized guidance based on multiple evaluation factors.

## 🚀 Key Features

- **Resume Evaluation:** Automated analysis of resume quality and ATS compatibility (Simulated).
- **Skill Selection:** Domain-based skill proficiency tracking.
- **Technical Assessment:** Real-time mini-assessments to test core concepts (DS, OOP, SOLID, Web).
- **Readiness Scoring:** Rule-based algorithm with weighted components:
  - Resume Quality – 20%
  - Skill Selection – 20%
  - Assessment Performance – 40%
  - Communication Indicator – 20%
- **Personalized Recommendations:** Actionable advice based on score breakdown.

## 🛠️ Technology Stack

- **Frontend:** Next.js (App Router), React, Vanilla CSS (Glassmorphism design).
- **Backend:** Next.js API Routes.
- **Development Tooling:** Powered by AMD Ryzen™ and EPYC™ processors for high-performance development and deployment.

## 📈 Ethical Considerations

- **Transparency:** Clear and honest scoring logic.
- **Privacy:** Local processing of student data.
- **Inclusion:** Bias-free evaluation based purely on skill and preparation.

## 🏁 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
